gpt2-fast

GPT-2, one measured step at a time

GPT-2 written from scratch in Rust, made faster one measured step at a time, and compiled to run in this browser on WebGPU or WebAssembly. Nothing you type leaves this tab.

Try it

The model starts loading as soon as the page opens and runs in a Web Worker on this device. Auto uses WebGPU when it is available, otherwise WebAssembly with threads or SIMD. The weights download once and stay in the browser's cache.

How it's measured

        

        

          

            The project numbers on this page come from
            results/log.jsonl. Native runs
            use a Linux container limited to
             cores and
             GB.
          

          

            Every milestone except N1 runs in
             fresh sessions. Each session
            gives every prompt  warm-up and
             timed runs of
             tokens. The reported
            number is the median of the session medians.
          

          

            Decode speed counts tokens after the first. Prompt speed is prompt
            tokens divided by time to first token. Time to first token is
            measured from the start of generation.
          

          

            Every run's output is compared with the PyTorch reference. A
            milestone must match all
             tokens and pass the
            logit check; quantized weights are judged by token agreement and
            perplexity and are shown separately.
          

          

            Prompts were kept only if the winning token leads the runner-up by
            at least  logit at every
            step, which leaves room for rounding differences. The closest margin
            in the set is .
          

          

            Browser numbers are labelled as browser numbers. They were measured
            in Chromium and WebKit on the development laptop, on the same
            prompts, not in the container. Your own numbers on this page are
            measured in this tab.
          

          

            Raw sessions and flame graphs are in
            results/runs/. The
            spec defines the protocol.

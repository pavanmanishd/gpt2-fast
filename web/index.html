How it's measured

        

        

          

            The project numbers on this page come from
            results/log.jsonl. Native runs
            use a Linux container limited to
             cores and
             GB.
          

          

            Every milestone except N1 runs in
             fresh sessions. Each session
            gives every prompt  warm-up and
             timed runs of
             tokens. The reported
            number is the median of the session medians.
          

          

            Decode speed counts tokens after the first. Prefill speed is prompt
            tokens divided by time to first token. Time to first token is
            measured from the start of generation.
          

          

            Every run's output is compared with the PyTorch reference. A
            milestone must match all
             tokens and pass the
            logit check; quantized weights are judged by token agreement and
            perplexity and are shown separately.
          

          

            Prompts were kept only if the winning token leads the runner-up by
            at least  logit at every
            step, which leaves room for rounding differences. The closest margin
            in the set is .
          

          

            Raw sessions and flame graphs are in
            results/runs/. The
            spec defines the protocol.
